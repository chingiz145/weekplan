# WeekPlan — установка как приложение на iPhone и Mac

Теперь планировщик — это **PWA** (устанавливаемое веб-приложение). Оно ставится
на домашний экран iPhone и в Dock на Mac, открывается в своём окне без адресной
строки и синхронизируется между всеми устройствами через облако **Supabase**
(бесплатно, без лимитов JSONBin).

Настройка занимает ~15 минут и делается один раз.

---

## Что входит в комплект

```
weekly-tasks/
├── index.html            ← само приложение
├── manifest.json         ← описание PWA (иконка, имя, режим окна)
├── service-worker.js     ← офлайн-режим и установка
├── icons/                ← иконки приложения
└── УСТАНОВКА-приложение.md ← эта инструкция
```

Все файлы должны лежать **вместе** и открываться по одному общему адресу (https).

---

## Шаг 1. Облако Supabase (хранилище задач)

1. Зайдите на [supabase.com](https://supabase.com) → **Start your project** → войдите
   через GitHub или email. Тариф Free — бесплатно навсегда.
2. **New project** → задайте имя (например `weekplan`), придумайте пароль базы
   (он не понадобится в приложении), регион выберите ближе (Frankfurt/Europe).
   Подождите ~2 минуты пока проект создаётся.
3. Слева откройте **SQL Editor** → **New query** → вставьте и нажмите **Run**:

   ```sql
   create table if not exists weekplan_data (
     sync_code  text primary key,
     payload    jsonb,
     updated_at timestamptz default now()
   );

   alter table weekplan_data enable row level security;

   create policy "anon full access"
     on weekplan_data for all
     to anon
     using (true) with check (true);
   ```

   Это создаёт таблицу для задач и разрешает приложению читать/писать в неё.

4. Слева **Project Settings** (шестерёнка) → **API**. Скопируйте два значения:
   - **Project URL** — вида `https://xxxxxxxx.supabase.co`
   - **anon public** ключ (длинная строка `eyJhbGci...`)

   Эти два значения безопасно держать в приложении — они рассчитаны на клиента.

---

## Шаг 2. Публикация приложения (получаем https-ссылку)

PWA обязательно нужен адрес `https://…` — с локального файла установка не работает.
Самый простой бесплатный способ — **Netlify Drop**:

1. Откройте [app.netlify.com/drop](https://app.netlify.com/drop)
2. Перетащите туда **всю папку** `weekly-tasks` целиком
3. Через несколько секунд получите ссылку вида `https://weekplan-xxx.netlify.app`

Готово — по этой ссылке приложение открывается с любого устройства.

> Альтернативы: GitHub Pages, Cloudflare Pages, Vercel — любой хостинг статики.
> Главное, чтобы `index.html`, `manifest.json`, `service-worker.js` и папка `icons`
> лежали в корне по одному адресу.

---

## Шаг 3. Подключаем облако в приложении

1. Откройте вашу ссылку в браузере
2. Нажмите кнопку **«Облако»** вверху справа
3. Вставьте:
   - **Project URL** — из шага 1.4
   - **anon public key** — из шага 1.4
   - **Код синхронизации** — придумайте любой (например `chingiz-2026`).
     Это как «имя комнаты»: на всех устройствах вводите **одинаковый** код, и они
     видят одни и те же задачи.
4. **Подключить**

Всё. Точка рядом с кнопкой станет фиолетовой — значит синхронизация активна.

---

## Шаг 4. Установка на устройства

### iPhone / iPad (Safari)
1. Откройте ссылку в **Safari** (обязательно Safari, не Chrome)
2. Нажмите кнопку «Поделиться» (квадрат со стрелкой вверх)
3. **«На экран Домой»** → **Добавить**
4. На домашнем экране появится иконка WeekPlan — открывается как обычное приложение
5. Внутри приложения нажмите **«Облако»** и введите те же URL, ключ и код

### Mac (Safari 17+)
1. Откройте ссылку в Safari
2. Меню **Файл → Добавить в Dock…**
3. Приложение появится в Dock и в Launchpad, откроется в своём окне

### Mac (Chrome) — альтернатива
1. Откройте ссылку в Chrome
2. Справа в адресной строке значок установки (монитор со стрелкой) → **Установить**

После установки на каждом устройстве один раз введите **облако** (URL + ключ + код) —
и задачи начнут синхронизироваться автоматически.

## Как работает синхронизация

- Любое изменение (добавил задачу, включил таймер, отметил выполненной) через
  ~1 секунду улетает в облако
- Каждые 5 секунд приложение проверяет облако и подтягивает изменения с других
  устройств; плюс синхронизируется каждый раз при открытии приложения
- **Фиолетовая точка** у кнопки «Облако» — статус: мигает = синхронизация идёт,
  горит = всё синхронизировано, красная = нет связи (проверьте интернет)
- Без интернета приложение работает офлайн, данные копятся локально и уедут в
  облако как только связь появится
- Кнопки экспорт/импорт файла остаются как резервная копия

## Частые вопросы

**Нужно ли платить?**
Нет. Supabase Free и Netlify Free покрывают такое использование с огромным запасом.

**Насколько это безопасно?**
Anon-ключ рассчитан на использование в клиенте. Доступ к вашим задачам защищён
кодом синхронизации — никто не увидит их, не зная и ключ, и код. Для личного
планировщика этого достаточно. Не публикуйте ссылку и код вместе.

**Хочу настоящее приложение в App Store**
Тогда следующий шаг — обернуть этот же код в Capacitor и собрать в Xcode
(нужен Mac и аккаунт Apple Developer, $99/год). Код приложения и облако остаются
теми же — меняется только «упаковка». Скажите — подготовлю проект Capacitor.

**Можно ли подключить телеграм-бота к этому облаку?**
Да. Бот (`bot.py`) можно переписать на запись в ту же таблицу Supabase вместо
JSONBin — тогда задачи из бота будут появляться в приложении. Скажите — сделаю.
