# WeekPlan

Недельный планировщик задач с таймерами, проектами, буфером и облачной
синхронизацией через Supabase. Устанавливается как приложение (PWA) на Mac и iPhone.

- `index.html` — приложение
- `manifest.json`, `service-worker.js`, `icons/` — PWA-обвязка
- Синхронизация настраивается внутри приложения (кнопка «Облако»)

Хостинг: Netlify (auto-deploy из этого репозитория).
